4. ASCII and Unicode

ASCII ( American Standard Code for Information Interchange) and Unicode is used to represent text characters. ASCII: Uses 7 bits to represent a single character (including letters, numbers and special symbols) Unicode: Uses 16 bits to represent a character, allowing for a much larger range of characters to be represented.
