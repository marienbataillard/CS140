1. Internet

Internet is connections between computers usually connected via fibre cables or satelite, where computers are able to share and send data over long distances

2. Web

Web is a in which system of sites and pages that is accessed through the internet to using browsers.

3. How are the Internet and Web different?

Internet is the infrastructure that connects computers, web is the application that is used on the computers , computers will not be able to communicate with each other without the internet and the web will not be able to work without the internet

4. ASCII and Unicode

ASCII ( American Standard Code for Information Interchange) and Unicode is used to represent text characters. ASCII: Uses 7 bits to represent a single character (including letters, numbers and special symbols) Unicode: Uses 16 bits to represent characters from many different languages, symbols, and emojis.

5. What is UTF-8?

UTF-8 (Unicode Transformation Format - 8-bit.): Character encoding used to represent Unicode characters so computers can store, send, and read text correctly.
Unicode = what characters exist
UTF-8 = how these characters are encoded for computers.

6. URL

URL (Uniform Resource Locator): Is the address of a specific resource (HTML pages, CSS documents and images etc.) on the web.

7. Domain Name

An easy to remember name used to identify a website, such as google.com.

8. HTTP

HTTP (Hypertext Transfer Protocol): Set of rules that defines how data is exchanged between a client (web browsers) and a server over the internet.

9. HTTPS

A more secure version of HTTP, where it encrypts the information sent between your browser andd website

10. IP Address

A unique numerical address used to identify a device or server on a network.

11. DNS

DNS (Domain Name System) Converts easy to remember domain names into IP addresses that computers can understand.

12. W3C Recommendations

Web standards and guidelines created by the W3C (World Wide Web Consortium) to help make the Web work consistently and be accessible to everyone.

13. XML, XHTML, HTML, HTML5

XML (Extensible Markup Language) : Language used to store and organize data in a structured way
XHTML (Extensible HyperText Markup Language): A stricter version of HTML that follows CML rules
HTML (HyperText Markup Language): The main language used to create and structure webpages.
HTML5: Modern version of HTML, with features for things like video, audio, graphics and modern web applications
