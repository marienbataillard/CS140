CSS Selectors

List out the different ways to select an item

  • ID
  • CLASSES
  • SPAN
  • DIV

What is the difference between ID and Class?

Besides the difference between the way they are used in a CSS file, ID should be unique to the page and is only used once in an area whereas CLASS can be repeated, it makes it so we can reuse it in different tags, also you can attach multiple classes into one tag by using a space.

What is the difference between a SPAN tag and a DIV tag?

Span selects a line to do something to it without breaking the line where as the DIV selects a block of text and breaks the line causing the next line to be on a new line.

What is the difference between a DIV tag and HEADER, MAIN and FOOTER?

What is the different ways to select a colour?

You can select a colour from the suggested colours or you can press on the square an adjust the colour to your liking. You can also use a hex code or RGB code to select a colour.
