Questions

1. Why is the viewport meta tag important?

The viewport meta tag helps a website display correctly on different devices, especially mobile phones. It allows the browser to match the page width to the device's screen width so the content is easier to read.

2. How can you adjust the CSS for printing?

I can use the @media print rule in CSS to change how a webpage looks when printed. For example, I can hide the navigation bar and sidebar, remove background colors, and arrange the cards in a single column.

3. When would you want to adjust the CSS for printing?

I would adjust CSS for printing when someone needs a paper copy of a webpage. Print styles can save ink, improve readability, and make sure important content fits neatly on the printed pages.
