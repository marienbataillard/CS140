Questions

1. Why do we need a viewport meta tag?

The viewport meta tag helps a website display look good or correctly on other devices, especially for mobiles. Matches the page with to screen width of the device to make it easier to read.

2. When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?

The latter. Both hold equal importance but which ever one is written last will take priority. So in this case f ro was the second line it would be row.

3. How do you change the CSS for a web page displayed on a phone?

Can use @media screen to adjust certain parts of the site to suit a mobile screen or desktop screen.

4. Pick a website you use on your phone. Name two things it changes on mobile compared to desktop.

BYUH Canvas. 1. NAV bar goes from the side in desktop to the top left in mobile as a drop down feature. 2. Sidebar, goes from the side but then is added to the top right corner in mobile as a drop down feature.

5. What width did you choose for your breakpoint, and why??

I chose 600px as my mobile breakpoint because the layout becomes harder to fit on smaller screens. For this part I stack the nav buttons make the cards into 1 column and make the sidebar at the end. I also made a 900px breakpoint only adjusting the cards to fit 2 column instead of 3.
