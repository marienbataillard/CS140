Explain the difference between inline, embedded, and external CSS.

  • Inline: CSS written directly inside html element using the style attribute.
  • Embedded: Written inside a style tag int the HTML document, usually inside the head
  • External: CSS written in a seperate css file and then connected to the HTMl documents


Explain why you should only use external CSS.

External CSS keeps the HTML and styling seperate, I guess to keep the documents more organised. CSS files also can be used for multiple HTML files.


What is a selector used for?
